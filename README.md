# Turn a YouTube comment export into a review worksheet

[English](README.md) · [简体中文](README.zh.md)

For teams that already have a comment export and need to hand it to someone for review. This script separates comments from collection-status records and puts the available parent comment beside each reply.

Python standard library only. No Apify token, YouTube requests, Actor execution or new collection charges.

## Run it

Install Python 3, extract the download, and run this command from its directory:

```sh
python review_comments.py sample-output.json --out output
```

You can also use `py` on Windows or `python3` on macOS / Linux. Running it again overwrites the three generated files in the selected output directory. Use a new directory once you have started adding review notes.

The historical sample produces:

- `comments-review.csv`: 40 comments — 19 top-level comments and 21 replies.
- `collection-status.csv`: 2 collection-status records, excluded from the comment count.
- `export-summary.json`: record counts, duplicate counts, parent matches and the source file's SHA-256.

Import the CSV into Excel or Google Sheets with ID columns set to text and automatic conversion of text to numbers, dates or formulas disabled. The script writes UTF-8 with a BOM and preserves the original text. `like_count` and `collected_at` describe the collection snapshot, not live values.

## Review the comments

Use `video_id` and `parent_comment_id` to find a discussion. `parent_comment_text` is matched from the same file, not generated by a model. `parent_in_export=false` means no matching parent was found in this export, not that the parent does not exist on the platform. Both columns are blank for top-level comments.

For example, the sample reply “What do you mean still?” addresses “still looks better than my renders”. It asks another viewer a question; a question mark alone does not make it a product inquiry.

Fill in `review_topic`, `next_action` and `owner` during review. `review_status` starts as `not_reviewed`. These are workflow columns, not Actor judgments. The script neither classifies sentiment nor sends replies.

## Use your own export

Complete the run you need in [YouTube Comments Scraper](https://apify.com/arjun_code/youtube-comments-scraper), download the JSON array without field filtering, then run:

```sh
python review_comments.py my-comments.json --out my-review
```

Keep `recordType`, `videoId` and `commentId`. Context matching also needs `parentCommentId`, `isReply` and `text`. The script deduplicates on `videoId + commentId`, keeping the first occurrence in the file. Do not use it to merge snapshots collected at different times. It loads the entire file into memory and is intended for small manual-review jobs, not large streaming workloads.
